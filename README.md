# Speech Spark

Website for Speech Spark, a student-led nonprofit teaching debate, speech, Model UN,
and communication through beginner-friendly camps, workshops, and chapters.

## Structure

- `index.html` and section pages (`about`, `programs`, `camps`, `chapters`, `volunteer`, `contact`)
- `css/` — `style.css`, `animations.css`, `responsive.css`
- `js/` — `main.js` (navigation, reveals, FAQ, counters), `gallery.js` (lightbox), `chapters.js` (map + directory)
- `data/chapters.json` — chapter list
- `assets/` — photos and chapter logos

## Running locally

Open `index.html` in a browser, or serve the folder:

    python3 -m http.server
